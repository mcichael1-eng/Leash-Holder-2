# Reader test: Appendix F (The Advanced Shelf), second pass

Appendix F was read in full, start to finish, as the intended reader: no computer-science background, a daily chatbot user who has read the 66 chapters (so a term defined in any chapter counts as defined, as long as the appendix names it recognizably or points to it). This is a second, independent pass; the first pass is in reader-test-appendix-1.md and its 17 edits were found intact. No earlier version of this report existed, so the pass started from the beginning.

Scope: all 110 entries and all 265 definition callouts were checked for correctness against standard textbook knowledge, and all 245 "Chapter N" references (including Table F.1 and Figure F.1) were checked against the chapters by grepping each target chapter for the connected idea and for its definition callout. The acronym list for Appendix F in acronyms-by-chapter.json (SNE, RBM, IEEE, CS229, DETR, CS2023, VM, DNN, AAAI) was worked through: all are now expanded or glossed at first use (VM and IEEE in this pass, the rest in the first).

Edits are small and surgical (Edit tool, exact-string replacements; the file was confirmed unchanged since it was read, immediately before editing). No headings, callout formats, figure or table numbers were changed. The definition count is still 265 and the entry count 110. After editing, `python3 tools/validate.py appendices/F-advanced-shelf.md` reports 3/3 diagrams valid with exit 0; a scripted check found no malformed definition lines and no emoji. `check.py` does not apply to appendices, and no chapter was edited.

## Flagged, not edited

- The killer microseconds: "a fast network round trip or a flash-storage read takes a few microseconds". A fast network round trip is a few microseconds, but a read from ordinary flash storage typically takes tens of microseconds. The article itself (CACM 60(4), 2017) could not be fetched to confirm its exact figures (CACM and the ACM Digital Library returned 403; the Google Research page confirms the authors and the microsecond-scale framing only), so the sentence was left as is. A safe wording, if a later pass can confirm, would be "from a few to a few tens of microseconds".
- `acronyms.py` will keep listing VM and IEEE for Appendix F because it counts only definition callouts, not inline glosses. Both are now expanded at first use.
